Revisión: no crear categoría si el tercero no quedó

Para comité

1. Necesidad o problema

Al revisar un comprobante, si el dato de la línea no es un afiliado, el alta del tercero no debe seguir a la categoría. Hoy esa alta no inserta fila y el proceso se cae en la categoría.

2. Análisis

Paso 0. No es capacitación. La revisión del comprobante existe. El defecto es el alta del tercero antes de la categoría.

DESAIX: SPK_INSERT_TERDEAFI, PREVERSION idéntica a la Cerrada 2.0.3 (anterior 2.0.2). El arreglo no está en canasta. Lo llama SPK_NC_REVISAMCPE con la categoría en blanco cuando el tercero de la línea no está en TER.

Qué falla antes de la categoría. El dato 1036339753 no está en AFI. El documento queda vacío. La búsqueda por NIT usa ese documento vacío y no encuentra al 060000000680. Marca crear el tercero e inserta desde AFI. Ese INSERT no inserta filas y no se comprueba. Después graba TEXCA y CAT responde la llave FK_TEXCA_TEXCAIDCATEGORIA.

Clasificación. Defecto del alta del tercero en la revisión. Sin cambio de contabilidad.

3. Alcance

Incluye SPK_INSERT_TERDEAFI: la búsqueda por NIT cuando no hay afiliado, la salida si el alta no insertó fila, y no grabar la categoría pedida cuando viene vacía o el tercero no existe. No cambia la numeración ni el comprobante. El script provisional aplica ese control mientras el desarrollo no está en preversión.

4. Restricciones

Publicar en preversión. No ejecutar el script provisional desde BA. Revisarlo y correr el archivo completo en la base que corresponda. Reemplaza el procedimiento. No anula comprobantes. No corrige solo el dato del movimiento 0100092720.

5. Criterios

1) Revisar el 0153000000092095 no se cae por la categoría.
2) Las líneas del comprobante quedan con el tercero 060000000680, no con el documento 1036339753.
3) El movimiento 0100092720 queda con el mismo tercero.
4) Si el alta desde el afiliado no inserta fila, no se graba categoría.

6. Recomendación

Llevar al comité el control en el alta del tercero. El script provisional queda para correrlo mientras el desarrollo no está publicado. No se ejecutó.

SELECT @DOCUMENTONIT = DOCIDAFILIADO FROM AFI WHERE IDAFILIADO = @TERCEROSINTER
IF NULLIF(LTRIM(RTRIM(@DOCUMENTONIT)), '') IS NULL
   SET @DOCUMENTONIT = @TERCEROSINTER
UPDATE MCHE SET IDTERCERO = @IDTERCERADO
WHERE NROCOMPROBANTE = @NROCOMPROBANTE AND IDTERCERO = @TERCEROSINTER
IF @PROCEDENCIA = 'INV'
   UPDATE IMOV SET IDTERCERO = @IDTERCERADO
   WHERE CNSMOV = @REFERENCIA1 AND IDTERCERO = @TERCEROSINTER

-- Entradas. SPK_NC_CONTAB_INV, al inicio de Credito.
IF COALESCE((SELECT IDTERCERO FROM IMOV WHERE CNSMOV=@CNSMOV),'') = ''
   OR NOT EXISTS (SELECT 1 FROM TER WHERE IDTERCERO = (SELECT IDTERCERO FROM IMOV WHERE CNSMOV=@CNSMOV))
   UPDATE IMOV SET IDTERCERO = DBO.FNK_VALORVARIABLE('IDTERCEROINSTALADO') WHERE CNSMOV=@CNSMOV
