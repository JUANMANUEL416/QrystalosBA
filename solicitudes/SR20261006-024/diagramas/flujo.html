Hoy frente a lo propuesto

Hoy

Defecto de filtros. Los valores enviados no son los que la consulta compara, y hay opciones duplicadas. Origen: pendiente peru-filtros-estado.

Propuesto (análisis del REQ)

Cada opción del filtro usa el mismo código y el mismo texto que la columna. Pendiente en notas filtra las pendientes. Rechazado y baja se distinguen en la lista.

Controles en la base de procesos

Resolución, token y API MiFact

Configuración · config-sunat

Misma pantalla /conf/fdian (ayuda habla DIAN/SUNAT). Token < 20 caracteres → el SP se devuelve sin enviar. URL < 30 → 'No existe api valida'. Fuera de BDATA_PRODUCCION usa RUC/token de prueba.

Invariante: Sin prefijo FDIAN coherente (FTR vs BOLE) no arma correlativo. No es BLOQUEADIAN de Colombia.

SP: SPK_GENERA_JSON_PERU_FACTURA · (SP)

Enviar factura a SUNAT (JSON)

Proceso propio · enviar-sunat-ftr

FE: Cerrar Factura / Notificar Sunat → FTR_COL · ENVIA_CONTAB. En Perú no aplica el control «ya contabilizado» (vuelve a ejecutar SPK_NC_CONTAB_FTR) y elige INTEGRA (TIPOFIN=C, FACTEP≠102) o FACTURA. Si ya hay FTRE, RETURN. Silencioso si valor ≤0, token <20 o URL <30. Corregir: LIBERAR_SUNAT. Quitar Error: QUITAR_ERROR_API (104A). INTER_SAP: Notificar Sunat SAP → SPK_JSON_FTR_PERU_INTERFAX (garante sin remesa no envía; valor 0 → 104A; OK → 102; error → 104).

Invariante: TIPOFIN=N → 03 boleta; si no → 01. MiFact: FTRE bloquea reenvío. Corregir no borra FTRE. Imprimir una factura financiera sin cerrar dispara ENVIA_CONTAB. Ningún permiso USGRUH protege los botones SUNAT.

SP: SPQ_FTR_COL · ENVIA_CONTAB, SPK_GENERA_JSON_PERU_FACTURA · (SP), SPK_GENERA_JSON_PERU_FTR_INTEGRA · (SP), SPQ_FTR_PERU · LIBERAR_SUNAT / QUITAR_ERROR_API / NOTIFICA_BOLETAS / MARCA_ENVIO / ENVIAR_FACTURA_SAP, SPK_CONSULTA_DOCUMENTO_ELECTRONICA · (SP), SPK_JSON_FTR_PERU_INTERFAX · (SP)

Enviar nota a SUNAT

Proceso propio · enviar-sunat-nota

MiFact: FNOT_ENVIARSUNAT → SPK_GENERA_JSON_PERU_NOTADBCR. INTER_SAP / cartera: SPK_JSON_FTR_PERU_INTERFAX_FNOT (EPreabono; lo llama FCXC/NOTASCXC). Si CNSDIANFE vacío, numera NCB/NCF o NDB/NDF.

Invariante: Si FNOT.FACTEP=OK no reenvía. Observación corta (<7) bloquea.

SP: SPQ_FNOT_COL · FNOT_ENVIARSUNAT, SPK_GENERA_JSON_PERU_NOTADBCR · (SP), SPK_JSON_FTR_PERU_INTERFAX_FNOT · (SP)

Estado Sunat con dos nombres

Proceso propio · estados-sunat-dos-nombres

Columna Est.Sunat: vacío=Sin Notificar, 103=Error Valida, 104=Rechazado, 104A=Rechazado-api, 105=Anulada, 108=Baja, resto (101/102)=OK. Filtro: Pendiente, En Proceso, Aceptado, Rechazado Sunat, Rechazado API, Anulado, Solicitud Baja (sin 103).

Invariante: Capacitar por código. 101 se ve OK pero aún está en proceso.

Valores afectos e identidad

Lo que llega · valores-y-tipo

Suma FTRD: afecto (PIVA>0) e inafecto. Copago resta. Si afecto+inafecto≤0 → RETURN. DNI afiliado a 8 dígitos. Código postal emisor/receptor fijo 150101 en el script leído.

Invariante: Sin detalle con valor no envía.
