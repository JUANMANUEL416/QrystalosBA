Nómina DIAN: horas con decimales y Cantidad entera

Necesidad para el plan de trabajo. No es un dictamen de implementación.

SR20261019-003
2026-10-19
Para comité

1. Necesidad o problema

Al generar el XML de nómina individual, SPK_GENERAR_XML_NOMINA compara las horas de las novedades (NEDIA) con la cantidad liquidada (VWK_NIEPED.CANTIDAD) usando variables INT. SQL Server redondea al asignar: 41.50 horas quedan en 42 y el procedimiento se detiene, aunque el dato real no sea 42. La suma de novedades tampoco incluye NEDIA.MINUTOS.

El atributo Cantidad del XML (incapacidades y licencias) es la cantidad de días y el esquema de la DIAN lo exige entero. Si se envía 1.50, SendNominaSync rechaza el documento con la regla ZB01.

Caso: NUMDOC 200000000087, CNSPAGO 02202609P30-1. Mensaje interno: incapacidad común, novedades 41, liquidación 42. Rechazo DIAN del 2026-10-19: archivo nie09002947942600046360, StatusCode 99, '1.50' is not a valid value for 'integer'.

2. Análisis

Proceso nomina, control de envío DIAN. El XML lo arma SPK_GENERAR_XML_NOMINA, llamado desde SPQ_NOM_DIAN · PREVIEW_XML y desde el procesamiento que transmite SendNominaSync. La ficha del objeto está en conocimiento de nómina (IXONLINE/SQL, PREVERSION = 2.0.7 al 2026-09-12).

Clasificación: defecto. El sistema ya genera el nodo de incapacidad y de licencia; el fallo está en el tipo de dato de la validación y en el formato del atributo Cantidad.

La validación interna debe distinguir 41.50, 41.00 y 42.00. El atributo que lee la DIAN es otro: días enteros. No se pide cambio de pantalla, de tablas ni de la liquidación ya causada.

3. Alcance

Solo SPK_GENERAR_XML_NOMINA, en los bloques de incapacidad común, profesional y laboral, y de licencia de maternidad o paternidad, no remunerada y remunerada. Incluye la variable de horas por día en decimal y el texto del mensaje de horas, que debe mostrar los dos decimales.

4. Restricciones

No cambiar liquidación, novedades, CUNE ni el atributo Pago. No quitar el RAISERROR: si a 2 decimales las horas no coinciden, el XML no se genera. No enviar Cantidad con punto decimal. Horas extras y el resto del procedimiento quedan igual.

5. Criterios

41.50 horas de novedad (41 h + 30 min) contra liquidación 41.50 genera el XML. 41.00 contra 42.00 sigue el error y el mensaje muestra los decimales, no un entero redondeado por el tipo INT.
En el XML, Cantidad de Incapacidad, LicenciaMP, LicenciaNR y LicenciaR no tiene punto decimal. 1.50 días queda en 2 y 1.49 en 1.
El reenvío del documento nie09002947942600046360, o del NUMDOC 200000000087, no recibe ZB01 por '1.50' is not a valid value for 'integer'.

6. Recomendación

Incluir en el plan de trabajo y publicar SPK_GENERAR_XML_NOMINA con la comparación en decimal y Cantidad entera. Después regenerar el XML del NUMDOC 200000000087 y notificarlo de nuevo.

7. Sugerencia de código SQL

Especificación para el comité y el desarrollador. No ejecutar desde BA. Contrastar PREVERSION vs última Cerrada antes de implementar.

-- Horas por día, sin división entera
SET @HORAS_X_DIA = CAST(@HORAS_DIA_LAB AS DECIMAL(14, 4))
    / NULLIF(CAST(@DIAS_MES_LAB AS DECIMAL(14, 4)), 0);

-- Validación interna (no se envía). @ID_DIAN: IncapacidadC, IncapacidadP, IncapacidadL, LicenciaMP, LicenciaNR, LicenciaR
SELECT @HORAS_NIEPED = ROUND(SUM(CAST(CANTIDAD AS DECIMAL(18, 4))), 2)
FROM DBO.VWK_NIEPED
WHERE CONSECUTIVO = @PERIODO AND NUMDOC = @NUMDOC AND ID_DIAN = @ID_DIAN;

SELECT @SUM_HORAS_NEDIA = ROUND(SUM(ROUND(
        CAST(NEDIA.HORAS AS DECIMAL(18, 4))
      + (CAST(ISNULL(NEDIA.MINUTOS, 0) AS DECIMAL(18, 4)) / 60.0), 2)), 2)
FROM NEDIA
INNER JOIN NEVE ON NEVE.IDEVENTO = NEDIA.IDEVENTO
INNER JOIN NCON ON NCON.CODCONCEPTO = NEVE.CODCONCEPTO
WHERE NEDIA.NUMDOC = @NUMDOC
  AND NEDIA.CNSPAGO IN (
        SELECT CNSPAGO FROM NIEPE
        WHERE NUMDOC = @NUMDOC AND CONCAT(ANO, MES) = @PERIODO)
  AND NCON.ID_DIAN = @ID_DIAN;

-- Variables DECIMAL(14, 2). Si difieren, el mensaje muestra 41.50, 41.00 o 42.00.
IF @SUM_HORAS_NEDIA <> @HORAS_NIEPED RAISERROR (...);

-- Cantidad del XML: días enteros (el XSD no admite 1.50)
CONVERT(VARCHAR(20), CONVERT(INT, ROUND(@HORAS_NEDIA / NULLIF(@HORAS_X_DIA, 0), 0)))
