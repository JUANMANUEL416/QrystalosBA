NC inventario: total con IVA en PDF, XML DIAN y contabilidad

Necesidad para el plan de trabajo. No es un dictamen de implementación.

SR20261016-002
Comite de Estudios Medicos (CEM)
2026-10-16
Para comité

1. Necesidad o problema

En notas credito generadas por devolucion o ajuste de factura de venta de inventario (insumos con IVA), el valor total creditado debe ser base + IVA (ej. NC 01C00000329 sobre FVCD1675: 9 x 198.667 = 1.788.003 + IVA ~339.721 = ~2.127.724). Hoy FNOT.VR_TOTAL queda solo en base; el PDF (fmtFnot01) desalinea columnas; DIAN puede rechazar CAU02; contabilidad puede dejar el renglon de IVA en cero.

2. Análisis

Clasificacion: defecto (generacion + contab + presentacion FE). Caso 01C00000329: FNOT.VR_TOTAL=1788003 vs total_esperado 2127723,57; lineas con VALORIVA OK.

Artefactos (BA / comite):
| Objeto | METODO / archivo | Rol |
| SPQ_GESVENTA | GEN_NC Parcial | IVA prorrateado; FNOT.VR_TOTAL tax-inclusive | TEMPORAL permitido |
| SPK_NC_CONTAB_FNOT | — | CR SUM(base+IVA); rama @VDB>@VCR NC inventario; DELETE DB 0 | Liberacion |
| SPQ_FNOT_IMPRESION | DATOSFNOT | Sin cambio; pie = FNOT.VR_TOTAL | — |
| fmtFnot01.js | Qrystalos2/src/boot/Fnot/ | Total linea base+IVA; %IVA; columnas | Liberacion FE |
| corregir_nc_inv_iva.sql | datos | Cabecera NC existente + SPK_NOTASCXC | Diferido prod |
| validacion / diagnostico_* | scripts | Evidencia comite | Soporte |

Nueva NC solo con SPQ_GESVENTA: validar FNOT.VR_TOTAL = SUM(VR_TOTAL)+SUM(VALORIVA), prevalidar XML, contabilizar y MCHE IVA <> 0. NC existentes requieren corregir + desmarcar contab.

3. Alcance

Incluye: fix GEN_NC inventario parcial, especificacion SPK_NC_CONTAB_FNOT, FE fmtFnot01, scripts de correccion y diagnostico para CEM, criterios regresion NC sin CNSMOV_DEV.

Fase temporal (ahora): solo SPQ_GESVENTA en ambiente no productivo o excepcion SQL acordada — aplica a notas credito NUEVAS desde GESVENTA.

Fase comite: resto del paquete en produccion + caso 01C00000329.

4. Restricciones

Produccion CEM: prohibido montar SPK_NC_CONTAB_FNOT, frontend, corregir_nc y recontabilizar/DIAN masivo hasta aprobacion y ventana.
Permitido: SPQ_GESVENTA temporal solo para nuevas NC (PREVERSION o acuerdo explicito).
NC FACTE 2/4: no UPDATE datos sin criterio legal.
No ejecutar corregir_nc_inv_iva en produccion mientras aplique restriccion.

5. Criterios

TEMPORAL (nueva NC parcial inventario tras SPQ_GESVENTA):
- FNOT.VR_TOTAL = SUM(FNOTD.VR_TOTAL)+SUM(FNOTD.VALORIVA).
- Prevalidacion DIAN sin CAU02; PayableAmount = total con IVA.
- Contabilidad: DB IVA > 0 en cuenta FTRD.CUENTA_FIMPDV; CR cartera = total con IVA.

LIBERACION (comite):
- Mismos criterios para NC existentes corregidas (01C00000329).
- SPK_NC_CONTAB_FNOT publicado; reconteo sin renglon IVA valor 0.
- PDF fmtFnot01: total linea y pie coherentes; CANTIDAD = unidades reales.
- Regresion: NC administrativa sin CNSMOV_DEV sin cambio indebido.

6. Recomendación

Comite: aprobar REQ FOR-DES / IXONLINE con los tres objetos (SPQ_GESVENTA, SPK_NC_CONTAB_FNOT, fmtFnot01). Mientras tanto CEM aplica solo SPQ_GESVENTA para nuevas devoluciones inventario y documenta en prueba. Caso 01C00000329 queda en cola para ventana unica (datos + contab + DIAN + FE).

7. Sugerencia de código SQL

Especificación para el comité y el desarrollador. No ejecutar desde BA. Contrastar PREVERSION vs última Cerrada antes de implementar.

-- ========== 1) TEMPORAL — IXONLINE/SQL · SPQ_GESVENTA · GEN_NC Parcial ==========
-- Archivo: solicitudes/SR20261016-002/sql/SPQ_GESVENTA.sql (copia de sql/SPQ_GESVENTA.sql)

VALORIVA por linea (prorrateo FTRD.VIVA):
ROUND(CASE WHEN COALESCE(FTRD.CANTIDAD,0) > 0
     THEN FTRD.VIVA * (#DATOS.CANTIDAD_A_DEVOLVER / FTRD.CANTIDAD)
     ELSE COALESCE(FTRD.VIVA,0) END, 2)

Cabecera tras INSERT FNOTD:
SELECT @VLR_TOTAL = SUM(VR_TOTAL), @VLR_IVA = SUM(COALESCE(VALORIVA,0)) FROM FNOTD WHERE CNSFNOT = @CNSFNOT
UPDATE FNOT SET VR_TOTAL = @VLR_TOTAL + @VLR_IVA, VALORCONCEPTO = @VLR_TOTAL + @VLR_IVA WHERE CNSFNOT = @CNSFNOT

-- ========== 2) LIBERACION — IXONLINE/SQL · SPK_NC_CONTAB_FNOT ==========
-- Archivo: solicitudes/SR20261016-002/sql/SPK_NC_CONTAB_FNOT.sql

-- CR cartera (NOTDBCR):
(SELECT SUM(D.VR_TOTAL)+SUM(COALESCE(D.VALORIVA,0)) FROM FNOTD D WHERE D.CNSFNOT=FNOT.CNSFNOT AND D.CLASE=FNOT.CLASE)
