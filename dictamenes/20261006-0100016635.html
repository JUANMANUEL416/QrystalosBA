1. Requerimiento del cliente

Incluir opción para descargar todo el detalle en formato XML (contexto: paquete FEV-RIPS). Se solicita poder descargar todo el detalle asociado a una cuenta de cobro desde el módulo Cuentas por cobrar. Detalle reportado: 1. Error en la descarga. 2. No descarga nada porque pide cambio de carpeta. 3. En una CXC de 100 o 5 facturas, solo descarga 1–4 FEV-RIPS como máximo. Expectativa: si la CXC tiene 100 facturas, obtener el FEV-RIPS de las 100 asociadas; ante error, indicarlo para corregir y completar la descarga.

Criterios de aceptación

1) En Cuentas por cobrar, cuenta con N facturas, botón «Descargar FEV-RIPS»: paquete de todas las facturas con CUV válido en uno o pocos ZIP (hasta 500 por archivo, como FEV/NC/NA-RIPS Masivo), sin depender de múltiples descargas automáticas del navegador. 2) Si el usuario cancela la selección de carpeta, continúa descarga directa de un único ZIP (o lote), sin quedar en cero archivos. 3) Al terminar: mensaje con exportadas vs omitidas; listado de omitidas con motivo (sin CUV, sin FTRJSON, JSON inválido, error PDF/XML). 4) ZIP con JSON RIPS, respuesta/CUV y XML DIAN según opciones; alineado con masivo (incl. opción XML). 5) Factura sin CUV: no entra al ZIP pero figura en informe con acción sugerida (validar en FEV/NC/NA-RIPS Masivo o Envíos y Respuestas). 6) Regresión ASOCABILIDOS (captura 14 ítems) y glosas (SopFevRips procedencia RESP_GLOSAS).

2. Análisis del coordinador

Paso 0 — ¿Ya existe? Clasificación: DEFECTO de confiabilidad/UX (no hueco de módulo). Capacitación complementaria solo para facturas aún sin CUV ministerio. Pantalla: Administrativo → Cuentas por cobrar (/admin/CuentasxCobrar, FCXCAComponent). Captura de referencia: detalle con columna FEVRIPS por fila y botón «Descargar FEV-RIPS». Inventario de caminos del control: • Descargar FEV-RIPS (lote CXC): abre diálogo de descarga masiva por CNSCXC. • FEVRIPS por factura: columna XML → Envíos y Respuestas (paquete individual). • FEV/NC/NA-RIPS Masivo: marcar por cuenta de cobro → Descargar (flujo ya mejorado en producto). • CXC Glosas: mismo componente de descarga con procedencia de respuesta de glosas. Causa técnica: el diálogo de cartera aún genera un ZIP por factura y dispara varias descargas del navegador (o escritura en carpeta vía API del navegador). Los navegadores bloquean descargas múltiples consecutivas → síntoma «solo 1–4 de 100». El flujo masivo administrativo ya usa ZIP maestro, subcarpetas, lotes de hasta 500 documentos, archivo de errores y diálogo de progreso. Backend: IXONLINE/SQL · SPQ_FCXC_COL · TRAER_CXC_VALIDADOS devuelve conteos y solo facturas con CUV en FTR unidas a FTRJSON; el resto suma como erradas sin detalle por factura. Alcance excluido: generar CUV, radicar CXC, cambios DIAN/FACTE, Perú SUNAT.

5.2.1 Fragmentos SQL (especificación)

Especificación para desarrollo en preversión. No ejecutar desde la oficina BA.

-- SPQ_FCXC_COL · METODO TRAER_CXC_VALIDADOS
-- Tras el segundo SELECT (facturas validadas), añadir tercer recordset:

SELECT FCXCD.N_FACTURA,
       CASE
         WHEN J.CNSFCT IS NULL THEN N'Sin FTRJSON: generar/validar RIPS antes de descargar'
         WHEN COALESCE(NULLIF(LTRIM(RTRIM(FTR.CUV)), N''), NULLIF(LTRIM(RTRIM(J.CUV)), N'')) IS NULL THEN N'Sin CUV del Ministerio'
         WHEN COALESCE(J.JSON_ENVIO, N'') IN (N'', N'{}') THEN N'JSON_ENVIO vacío en FTRJSON'
         ELSE N'No cumple criterio de exportación'
       END AS MOTIVO
FROM FCXCD
INNER JOIN FTR ON FCXCD.N_FACTURA = FTR.N_FACTURA
LEFT JOIN FTRJSON J ON FTR.CNSFCT = J.CNSFCT
WHERE FCXCD.CNSCXC = @CNSCXC
  AND (
        J.CNSFCT IS NULL
     OR COALESCE(NULLIF(LTRIM(RTRIM(FTR.CUV)), N''), NULLIF(LTRIM(RTRIM(J.CUV)), N'')) IS NULL
     OR COALESCE(J.JSON_ENVIO, N'') IN (N'', N'{}')
      );

-- Validación (solo lectura):
SELECT FCXCD.CNSCXC, COUNT(*) AS total,
       SUM(CASE WHEN COALESCE(FTR.CUV,N'')<>N'' AND J.CNSFCT IS NOT NULL THEN 1 ELSE 0 END) AS exportables
FROM FCXCD
INNER JOIN FTR ON FCXCD.N_FACTURA=FTR.N_FACTURA
LEFT JOIN FTRJSON J ON FTR.CNSFCT=J.CNSFCT
WHERE FCXCD.CNSCXC = @CNSCXC
GROUP BY FCXCD.CNSCXC;

6. Qué tener en cuenta
