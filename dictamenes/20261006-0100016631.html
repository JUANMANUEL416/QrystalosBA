1. Requerimiento del cliente

Discrepancia en el valor de pago de factura Al intentar aplicar un pago a una factura, el valor mostrado no coincide con el saldo disponible. Se requiere asistencia para resolver esta discrepancia. DETALLE: Se solicita un botón para liberar la factura que quedó marcada como pago cuando FCXCDV.MARCAPAGO = 1. El sistema, cuando arroja algún error en el proceso de pago, deja la marca activa sin forma de quitarla y no la limpia con el tiempo. Contexto: la factura se marca en FPAG durante el recaudo; si al aplicar no se libera FCXCDV y queda saldo, al volver a aplicar no la muestra. Se necesita que, al aplicar el recaudo con éxito o mediante una utilidad segura, se libere FCXCDV para que el saldo residual vuelva al buscador de Recaudos.

Criterios de aceptación

1) En Recaudos → asignar facturas (CXCComponent), la grilla solo muestra vencimientos con FCXCDV.MARCAPAGO=0; si hay saldo pero la factura no aparece, el usuario puede abrir «Facturas huérfanas» y desmarcar las que no estén en RPDX/FPAGD de un recaudo abierto. 2) LIBERAR_MARCAPAGO: si MARCAPAGO=1 sin vínculo activo, UPDATE FCXCDV.MARCAPAGO=0 y la factura vuelve al buscador sin SQL manual. 3) Si la marca está en staging RPDX o FPAGD de un recaudo abierto, el sistema informa CNSFPAG/usuario y no libera hasta quitar la línea (DEL_FACTURA / Quitar del detalle / BORRARTODO). 4) QUITARFPAGD (recaudo abierto): al retirar una línea del detalle, desmarcar FCXCDV sin depender de FPAGD ya borrado. 5) Tras Aplicar recaudo exitoso (SPK_PAGOSCXC), vencimientos con saldo residual quedan con MARCAPAGO=0 (caso ASFE95817 con recaudos parciales). 6) No altera saldos contables, MCP ni FPAG cerrados; solo el candado de asignación en FCXCDV.

5. Cambios propuestos

5.0 En palabras simples (negocio)

Cuando una factura queda «marcada en pago» sin un recaudo real detrás, hoy no sale en el buscador de Recaudos y soporte la desbloquea por SQL. Se propone usar (o desplegar) la pantalla «Facturas huérfanas» para desmarcar con reglas, corregir quitar línea del recaudo para que no deje la marca pegada, y mantener la desmarca automática al aplicar el pago con éxito.

5.1 Detalle técnico — Frontend (Qrystalos2)

  • Ruta /admin/Recaudos — en el control «Asignar facturas», toolbar con botón Facturas huérfanas (color naranja, icono unlock).
  • Diálogo: carga LISTAR_FACTURAS_HUERFANAS por IDTERCERO; tabla N_FACTURA, TIPO, CNSCXC, CNSGLO, SALDONETO; acción Desmarcar → LIBERAR_MARCAPAGO con LIBERAR=1.
  • Tras OK (ESTADO=LIBERADA), refrescar grilla VWK_CXC1 (MARCAPAGO=0).
  • Mockup UX del caso documenta la ventana propuesta (toolbar + diálogo), no la captura del problema.
  • Opcional: si búsqueda por N_FACTURA vacía y existe MARCAPAGO=1, banner con diagnóstico LIBERAR_MARCAPAGO (LIBERAR=0).
  • Permiso USGRUH: alinear a operaciones de recaudo abierto (coordinación confirma IDCONTROL).

5.2 Detalle técnico — SQL Server

Fuente: IXONLINE/SQL · SPQ_FPAG_COL (PREVERSION). Especificación — no ejecutar desde este documento.

A) METODOs LISTAR_FACTURAS_HUERFANAS y LIBERAR_MARCAPAGO

  • LISTAR: FCXCDV con MARCAPAGO=1, SALDONETO>0, tercero (incl. TERFU), sin RPDX/FPAGD en recaudo CERRADO=0.
  • LIBERAR: estados RPDX_ACTUAL, FPAGD, HUERFANA; solo UPDATE si HUERFANA y LIBERAR=1 (clave N_FACTURA+TIPO+CNSGLO/CNSCXC).

B) Corrección QUITARFPAGD (CERRADO=0)

  • SELECT CNSCXC, CLASE, CNSGLO de FPAGD antes de DELETE; UPDATE FCXCDV MARCAPAGO=0; luego DELETE FPAGDI/FPAGD y EXEC SPK_FPAG.

C) SPK_PAGOSCXC · APLICAR

  • Sin cambio en este REQ: ya ejecuta UPDATE FCXCDV SET MARCAPAGO=0 por línea aplicada (tipo F y G/R/C).

-- IXONLINE/SQL · SPQ_FPAG_COL · PREVERSION (METODOs nuevos ya en canasta)
-- A) LIBERAR_MARCAPAGO + LISTAR_FACTURAS_HUERFANAS: diagnóstico RPDX/FPAGD; si HUERFANA y LIBERAR=1 → UPDATE FCXCDV.MARCAPAGO=0 por N_FACTURA+TIPO+(CNSGLO|CNSCXC).

-- B) QUITARFPAGD · recaudo abierto (BEFORE — liberada / build sin fix)
DELETE FPAGDI ...
DELETE FPAGD ...
UPDATE FCXCDV SET MARCAPAGO = 0
FROM FCXCDV INNER JOIN FPAGD ON ...  -- FPAGD ya no existe → no desmarca

-- AFTER (PREVERSION)
SELECT @CNSCXC = CNSCXC, @GRUPOETAREO = CLASE, @CNS5 = COALESCE(CNSGLO,'')
FROM FPAGD WHERE CNSFPAG = @CNSFPAG AND N_FACTURA = @N_FACTURA AND ITEM = @ITEM
DELETE FPAGDI ...
DELETE FPAGD ...
IF @GRUPOETAREO = 'G'
  UPDATE FCXCDV SET MARCAPAGO = 0 WHERE N_FACTURA = @N_FACTURA AND TIPO = @GRUPOETAREO AND CNSGLO = @CNS5
ELSE
  UPDATE FCXCDV SET MARCAPAGO = 0 WHERE N_FACTURA = @N_FACTURA AND TIPO = @GRUPOETAREO AND CNSCXC = @CNSCXC
EXEC SPK_FPAG @CNSFPAG

-- C) SPK_PAGOSCXC · APLICAR (referencia)
UPDATE FCXCDV SET MARCAPAGO = 0
WHERE CNSCXC = @CNSCXC AND N_FACTURA = @N_FACTURA AND TIPO = 'F';

-- Validación (solo lectura)

6. Qué tener en cuenta

  • Clave de vencimiento: N_FACTURA + TIPO + CNSGLO en FCXCDV (factura F vs glosa G).
  • TERFU: filtro de tercero en CXCComponent; LISTAR/LIBERAR usan el mismo IDTERCERO del FPAG.
