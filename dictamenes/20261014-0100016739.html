5. Cambios propuestos

5.0 En palabras simples (negocio)

Hoy el sistema genera el FURIPS1 dejando vacíos el ingreso, el egreso y el médico aunque la admisión y la historia clínica sí tienen esos datos, sobre todo cuando se radica por factura o la procedencia se elige mal. Se propone que el programa tome la atención desde la factura SOAT, complete fechas y profesional desde admisión/historia clínica, y que el archivo JSON de radicación incluya esos mismos campos.

5.2 Detalle técnico — SQL Server

  • Objeto: SPQ_FURIPS (IXONLINE/SQL PREVERSION 2.0.9).
  • METODOs: FURIPS y FURIPSCXC (cabecera recordset 1, ramas QX/CI/CE).
  • Tras leer @FTR: alinear @PROCEDENCIA (SALUD→QX) y @NOREFERENCIA desde FTR.
  • Rama QX: join HADM por referencia de factura si @NOREFERENCIA vacía; MED con OUTER APPLY TOP 1 HCA.IDMEDICO.
  • Ramas CI/CE: mismo criterio de referencia desde FTR; MED = COALESCE(C.IDMEDICO, HCA.IDMEDICO) donde aplique.

5.2.1 Fragmentos SQL (especificación)

Especificación para desarrollo; no ejecutar desde Qrystalos BA.

-- Objeto: SPQ_FURIPS · METODO FURIPS (IXONLINE/SQL PREVERSION 2.0.9)

-- Bloque 1: después de asignar @FTR (~línea 98)
IF @FTR <> ''
BEGIN
  SELECT TOP 1
    @PROCEDENCIA = CASE WHEN FTR.PROCEDENCIA = 'SALUD' THEN 'QX' ELSE FTR.PROCEDENCIA END,
    @NOREFERENCIA = CASE WHEN COALESCE(@NOREFERENCIA,'') = '' THEN FTR.NOREFERENCIA ELSE @NOREFERENCIA END
  FROM FTR
  WHERE FTR.N_FACTURA = @FTR AND FTR.ESTADO = 'P' AND COALESCE(FTR.TIPOANULACION,'') <> 'NC';
END

-- Bloque 2: rama QX — HADM
-- BEFORE: B.NOADMISION = @NOREFERENCIA
-- AFTER: B.NOADMISION = COALESCE(NULLIF(@NOREFERENCIA,''), (SELECT TOP 1 FTR2.NOREFERENCIA FROM FTR FTR2 WHERE FTR2.N_FACTURA = @FTR AND FTR2.PROCEDENCIA = 'SALUD' AND FTR2.ESTADO='P'))

-- Bloque 3: rama QX — MED + HCA
OUTER APPLY (
  SELECT TOP 1 HCA.IDMEDICO FROM HCA
  WHERE HCA.NOADMISION = B.NOADMISION AND COALESCE(HCA.IDMEDICO,'') <> ''
  ORDER BY HCA.FECHA DESC
) HCA_M
LEFT OUTER JOIN MED M ON M.IDMEDICO = COALESCE(B.IDMEDICOTRA, B.IDMEDICOING, HCA_M.IDMEDICO)

-- Validación (ejemplo):
-- EXEC SPQ_FURIPS ... FACTURA='<factura GE0004>' con NOREFERENCIA vacía
-- Esperado: CAMPO80, CAMPO82, CAMPO90–96 no vacíos si HADM/HCA/MED tienen datos.
