1. Requerimiento del cliente

Modificación de información en el Historial de Empleados. Se solicita una funcionalidad que permita modificar el centro de costo y el área funcional asociada a cada empleado en el historial de empleados de nómina. 1. El sistema permite modificar el centro de costo de un empleado desde su historial. 2. El sistema permite modificar el área funcional de un empleado desde su historial. 3. Los cambios se guardan en la base de datos. 4. Se muestra un mensaje de confirmación al usuario tras guardar.

6. Cambios propuestos

6.1 Frontend

  1. En crear/editar histórico: área funcional desde catálogo AFU (no texto libre).
  2. Campo centro de costo (NEMPHIS.CCOSTO) con descripción CEN, filtrado por el área elegida y centros Activo (misma regla que Cargos).
  3. Si cambia el área, limpiar o exigir reelección del centro incompatible.
  4. Ampliar ColumnasVisibles con NEMPHIS.CCOSTO y CEN.DESCRIPCION (join a CEN).
  5. Notificación de éxito actual de GUARDAR se mantiene; refrescar la grilla.

6.2 SQL Server

Pendiente Documentar: bajar SPQ_NOM_NEMPHIS.sql y fichar GUARDAR / ELIMINAR. Confirmar si el UPDATE ya persiste IDAREA y CCOSTO, si valida FK AFU/CEN y si sincroniza NEMP. No inventar columnas ni triggers TK_NEMPHIS_* salvo bug demostrado.
