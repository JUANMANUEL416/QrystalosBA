Control de este REQ (Perú · CMV · MER)

Facturar CMV — mecanismo MER

Clínica Internacional Perú · PPT.TIPOFACPE='MER'

Administrativo → Facturación Perú → pestaña Facturar CMV (Clínica Virtual). Permisos CALIFICACION_CMV / FACTURACION_CMV. Caminos: Períodos MER (bolsa mensual por grupo de garantes) → Calificación (aprobar servicios) → Facturación tipo MER (marcar, encolar). Una factura MER = línea consulta valorizada + PPS en la misma FTR. Hoy: valor consulta = bolsa ÷ Q citas; propuesto: factores por plan de atención (AGUDO, CRÓNICO, UIR, OMT) y unidades de referencia.

Invariante: MER exige mes completo en fechas. CPM y PPS en CMV conservan reglas actuales. Cola SPK_ENCOLAR_FTRMASI_PE / SPK_PROCESAR_FTRMASI_PE con CLASE=CV, TIPO=MER.

SP: SPQ_FTR_CMV · CRUD_PPTMER, PREVIEW_MER, CALIFICAR_*, FACTURAR_MASI_CMV · VWK_PROGRAMA_CMV · SPK_FACTURACMV_PERU

Fuera de alcance de este diagrama (Colombia / otros circuitos Perú): notificación DIAN (FEV), FEVRIPS Colombia, factura financiera FTR_COL, empaquetar y radicación CXC. Documento electrónico SUNAT/Interfax, si aplica a la FTR ya generada, queda en proceso json-peru y no forma parte de este cambio MER.

Alcance

Control Facturar CMV (Clínica Virtual) — mecanismo MER (`PPT.TIPOFACPE='MER'`): configuración de bolsa mensual compartida (`PPTMER` / grupo `PPTMERD`), cálculo de valor consulta, vista `VWK_PROGRAMA_CMV`, métodos API `FTR_CMV`, motor `SPK_FACTURACMV_PERU` y encolado `SPK_ENCOLAR_FTRMASI_PE` / `SPK_PROCESAR_FTRMASI_PE` cuando `TIPO=MER`/`CLASE=CV`. UI: `FTRCMVComponent.vue`, `PPTMERComponent.vue`. Documentación viva: runbook facturación CMV/MER, tablas PPTMER y VWK_PROGRAMA_CMV.
