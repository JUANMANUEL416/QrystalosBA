1. Requerimiento

Al crear un ítem de detalle de factura (FTRD), el sistema debe traer por defecto el mismo IDPLAN de la cabecera (FTR), para que el usuario no elija un plan distinto.

2. Criterios de aceptación

  1. Al Agregar Item, el detalle muestra el IDPLAN de la cabecera sin selección manual.
  2. Al guardar, FTRD.IDPLAN = FTR.IDPLAN de esa factura.

3. Análisis

Pedido simple: heredar el plan de cabecera al crear el detalle. La pantalla es Administrativo → Facturación → Facturas → Agregar Item (FTRComponent.vue). No hace falta cambiar stored procedures: el frontend debe enviar siempre el IDPLAN de cabecera.

4. Solución

  • Archivo: Qrystalos2/src/components/administrativo/ftr/FTRComponent.vue
  • Cambio: en NuevoFtrd / onResetREFD, asignar modelFtrd.IDPLAN = model.IDPLAN (y descripción).
  • Si el detalle permite editar o elegir plan, dejarlo solo lectura o quitar el selector.
