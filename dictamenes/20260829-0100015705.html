1. Requerimiento

Cuando la admisión está paquetizada (HADM.PAQUETE), el usuario debe entender qué se cobra al agregar o retirar un cargo del paquete. PAQUETE = 1: se cobra el servicio del paquete más lo que se retire. PAQUETE = 2: solo se cobra lo que se retire del paquete. La misma lógica debe verse al facturar. El coordinador indicó que no se requiere SQL nuevo (cambio de textos / avisos en pantalla).

2. Flujo de ejecución

Admisiones → abrir admisión → Catálogo de cargos (HPRE)
        │
        ├─ HADM.PAQUETE = 0 ──► sin botones de paquete (igual que hoy)
        │
        └─ HADM.PAQUETE = 1 o 2
                 │
                 ├─ Banner: «Contrato / admisión paquetizada (tipo 1 o 2)» + texto de cobro
                 ├─ Agregar / Quitar (toolbar y por fila): tooltip o aviso con el impacto
                 └─ Facturar (FTRHADM): mismo aviso de tipo de paquete
