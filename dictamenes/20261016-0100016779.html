1. Requerimiento del cliente

Cambio de palabra 'varios' en consecutivo de facturación masiva SOAT Al realizar la facturación masiva en el módulo de SOAT, el sistema muestra la palabra 'varios' en el consecutivo. Se solicita cambiar esta palabra por el último consecutivo que se facturó de cita. 1. Acceder al módulo de SOAT. 2. Realizar una facturación masiva. 3. Observar el consecutivo generado. DETALLE: Solicitud devuelta por segunda vez por el mismo argumento. Contexto técnico acordado: cuando en FTR la referencia sea «varios» u otros agrupadores (no un número real de prestación), resolver un ítem representativo según procedencia (CI → cita, CE → autorización). No es cambio en la tabla HACTRAND; es visual para alinear la grilla con el resto de filas.

5.2.1 Fragmentos SQL (especificación)

Especificación de proyección para columnas_visibles. No ejecutar desde Qrystalos BA.

-- Especificación de proyección (solo lectura en AppStore.read / HactrandComponent.vue)
-- Reemplazar HACTRAND.NOREFERENCIA en columnas_visibles por:

CASE
  WHEN UPPER(LTRIM(RTRIM(HACTRAND.NOREFERENCIA))) IN ('VARIOS','UNIWEB','CEUNIFICADO','MASIVA')
  THEN COALESCE(
    CASE WHEN HACTRAND.PROCEDENCIA = 'CI' THEN (
      SELECT TOP 1 CIT.CONSECUTIVO
      FROM FTR F
      INNER JOIN FTRD FD ON F.CNSFCT = FD.CNSFTR AND FD.PROCEDENCIA = 'CI'
      INNER JOIN CIT ON CIT.CONSECUTIVO = FD.NOADMISION AND CIT.CNSHACTRAN = HACTRAN.CNSHACTRAN
      WHERE F.N_FACTURA = COALESCE(NULLIF(HACTRAND.N_FCT_ASEG,''), NULLIF(HACTRAND.N_FCT_FYG,''))
        AND F.NOREFERENCIA IN ('VARIOS','UNIWEB','CEUNIFICADO','MASIVA')
        AND COALESCE(F.ESTADO,'P') <> 'A'
        AND COALESCE(F.TIPOANULACION,'') <> 'NC'
      ORDER BY CIT.CONSECUTIVO DESC
    ) END,
    CASE WHEN HACTRAND.PROCEDENCIA = 'CE' THEN (
      SELECT TOP 1 AUT.NOAUT
      FROM FTR F
      INNER JOIN FTRD FD ON F.CNSFCT = FD.CNSFTR AND FD.PROCEDENCIA = 'CE'
      INNER JOIN AUT ON AUT.IDAUT = FD.NOADMISION AND AUT.CNSHACTRAN = HACTRAN.CNSHACTRAN
      WHERE F.N_FACTURA = COALESCE(NULLIF(HACTRAND.N_FCT_ASEG,''), NULLIF(HACTRAND.N_FCT_FYG,''))
        AND F.NOREFERENCIA IN ('VARIOS','UNIWEB','CEUNIFICADO','MASIVA')
        AND COALESCE(F.ESTADO,'P') <> 'A'
        AND COALESCE(F.TIPOANULACION,'') <> 'NC'
      ORDER BY AUT.NOAUT DESC
    ) END,
    HACTRAND.NOREFERENCIA
  )
  ELSE HACTRAND.NOREFERENCIA
END AS NOREFERENCIA
