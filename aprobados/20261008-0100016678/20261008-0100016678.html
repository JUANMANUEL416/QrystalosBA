1. Requerimiento del cliente

Se solicita que el sistema no marque en FNOT contabilizada sin que el número de comprobante exista en MCP. Contexto: la nota queda con CONTABILIZADA = 1 y NROCOMPROBANTE lleno, pero el comprobante nunca llegó a contabilidad (movimiento diario). Se debe adicionar una validación para confirmar que el comprobante sí quedó en MCP.

5. Cambios propuestos

5.0 En palabras simples (negocio)

Hoy el sistema puede dejar una nota como «contabilizada» con un número de comprobante que no está en el movimiento diario (MCP). Se propone que, antes de marcar la nota como contabilizada, el sistema confirme que ese comprobante existe realmente en contabilidad; si no existe, la nota vuelve a pendiente o error y el usuario puede reenviarla desde Otros Módulos o Conciliaciones, igual que con cuentas por pagar.

  2. Conciliaciones (pestaña Notas): si se implementa RESET NOTDBCR, botón «Desmarcar contabilizado» alineado al patrón CxP (CONTABILIDAD_3 · RESET_CONTABILIZADO con PROCEDENCIA NOTDBCR).
  3. Mockup UX de referencia: ventana propuesta Otros Módulos → Notas (estado coherente y acciones reenviar/desmarcar), no la captura SSMS del problema.

5.2 Detalle técnico — SQL Server

  • SPK_NC_REVISAMCPE — guard EXISTS MCP en rama NOTDBCR antes de UPDATE FNOT CONTABILIZADA = 1.
  • SPK_NC_CONTAB_FNOT — al iniciar, reset FNOT huérfana (CONTABILIZADA = 1 + NROCOMPROBANTE sin MCP) para permitir recontabilizar.
  • SPK_REVERSAR_MCP — rama REVNOTDBCR: mover UPDATE FNOT después de EXEC SPK_NC_REVISAMCPE exitoso.
  • SPQ_CONTABILIDAD_3 · RESET_CONTABILIZADO — rama NOTDBCR (CONTABILIZADA = 0, MARCACONT = 0, NROCOMPROBANTE = NULL).
  • Script de saneamiento puntual y consulta de integridad (operación en copia/preversión).

5.2.1 Fragmentos SQL (especificación)

Especificación para desarrollo en PREVERSION (IXONLINE/SQL). No ejecutar desde Qrystalos BA.

-- 1) SPK_NC_REVISAMCPE — rama NOTDBCR, antes de UPDATE FNOT (dentro del BEGIN TRAN):
IF @PROCEDENCIA = 'NOTDBCR'
BEGIN
   IF NOT EXISTS (
      SELECT 1 FROM MCP
      WHERE NROCOMPROBANTE = @NROCOMPROBANTE
        AND COMPANIA = @COMPANIA
        AND COALESCE(ANULADO,0) = 0
   )
   BEGIN
      RAISERROR(N'No se marca FNOT contabilizada: el comprobante %s no existe en MCP.', 16, 1, @NROCOMPROBANTE)
   END
END

-- 2) SPK_NC_CONTAB_FNOT — detectar huérfano previo:
IF EXISTS (
   SELECT 1 FROM FNOT
   WHERE CNSFNOT = @CNSFNOT AND CLASE = @CLASE
     AND COALESCE(CONTABILIZADA,0) = 1
     AND COALESCE(NROCOMPROBANTE,'') <> ''
     AND NOT EXISTS (
        SELECT 1 FROM MCP M
        WHERE M.NROCOMPROBANTE = FNOT.NROCOMPROBANTE
          AND M.COMPANIA = @COMPANIA
          AND COALESCE(M.ANULADO,0) = 0
     )
)
BEGIN
   UPDATE FNOT SET CONTABILIZADA = 0, MARCACONT = 0, NROCOMPROBANTE = NULL
   WHERE CNSFNOT = @CNSFNOT AND CLASE = @CLASE
END

-- 3) SPK_REVERSAR_MCP — REVNOTDBCR: UPDATE FNOT después de SPK_NC_REVISAMCPE exitoso

-- 4) SPQ_CONTABILIDAD_3 · RESET_CONTABILIZADO — rama NOTDBCR (patrón CXP)

-- 5) Validación / saneamiento (copia):
SELECT FNOT.CNSFNOT, FNOT.CLASE, FNOT.NROCOMPROBANTE
FROM FNOT
WHERE COALESCE(FNOT.CONTABILIZADA,0) = 1
  AND COALESCE(FNOT.NROCOMPROBANTE,'') <> ''
  AND NOT EXISTS (
      SELECT 1 FROM MCP M
      WHERE M.NROCOMPROBANTE = FNOT.NROCOMPROBANTE
        AND COALESCE(M.ANULADO,0) = 0
  );
