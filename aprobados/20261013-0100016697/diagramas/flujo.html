Controles en la base de procesos

Variables y servicio FEV-RIPS

Configuración · config-fevrips

CONFIG_GENE_FEV (JSON: procedenciasSinAsync, valorMinimoAsync) decide segundo plano o inmediato; sin variable o JSON inválido → segundo plano. FEVRIPS_MODO=MICROSERVICIO activa FEVRIPS_COLA. El JWT SISPRO se guarda 60 min en TRANSIENT (JWT_RIPS) por usuario.

Invariante: Sin FACTE=2 el motor no genera. Sin CUV en la FV no hay AJUSTE ni NC/ND.

SP: FNK_RIPS_JSON_USAR_ASYNC · (función)

Conf. async: valores por defecto

Configuración · conf-async-discrepancia

Sin CONFIG_GENE_FEV la BD usa segundo plano para todo, pero el diálogo Conf. async abre con todas las procedencias como inmediatas. Guardar sin cambios vuelve todo síncrono. El diálogo no valida permiso USGRUH.

Invariante: Revisar la lista antes de guardar. Cambia la variable de toda la institución.

SP: SPQ_USVGS_COL · ACTUALIZA_DATO

Qué facturas lista el masivo

Proceso propio · filtro-masivo

Pestaña FEV-RIPS: FACTE=2, FDIAN.FTRELECTRONICA=1, FDIAN.PROCEDENCIA FTR/FPOS, SI=0, ESTADO=P, CONTABILIZADA≠0, VR_TOTAL>0, PROCEDENCIA≠CAJA, TIPOANULACION≠NC, YEAR(F_FACTURA)>2024. Validados = CUV lleno; Con Error = existe FTR_MAS_LOG FEVRIPS.

Invariante: Una factura fuera de este filtro no aparece: no es defecto.

Generar RIPS JSON

Proceso propio · generar-json

FE: useRipsJsonAsync. Síncrono RIPS_JSON o INICIAR_RIPS_JSON_JOB → EJECUTAR_RIPS_JSON_ASYNC (polling 15 s, hasta 60 min). Reintenta 3 veces si SQL reporta deadlock. Motor SPK_GENERAR_RIPS_JSON despacha la hoja según CAPITADA+TIPOCAP+TIPOFAC+PROCEDENCIA+PPT.PGP.

Invariante: FACTE=2. GENERAR=NO reusa JSON_ENVIO si existe. SOLO_META no arma payload. Factura anulada o con NC: la pantalla bloquea Generar y Validar.

Marcar, enviar y CUV

Proceso propio · enviar-cuv
