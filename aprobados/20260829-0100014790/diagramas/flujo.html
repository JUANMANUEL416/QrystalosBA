FEVRIPS (RIPS + FEV + CUV ministerio)

Subproceso unido (empaque y RIPS) · rips-fev

Circuito **normativo salud** (SISPRO/ministerio): JSON RIPS + factura DIAN + **CUV**. Distinto de encolar DIAN y de radicar CXC. Precondición usual: FACTE=2. Flujo: generar JSON (FTR_COL · RIPS_JSON → SPK_GENERAR_RIPS_JSON; async INICIAR/EJECUTAR_RIPS_JSON_JOB si CONFIG_GENE_FEV) → marcar/enviar (MODELO RIPS: GET_DATOS, SET_DATOS, MARCAFAC, GET_DATOS_XML…) → cola microservicio opcional (FEVRIPS_COLA si USVGS FEVRIPS_MODO=MICROSERVICIO: TOMAR_MANUAL/ENCOLAR/ESTADOS evita CUV duplicado) → recuperar CUV (FEVRIPS_COL · NOTA_AJUSTE) → descarga paquete ZIP (FTREComponent, FEVRIPSMasivoComponent FV/NC/NA). Validaciones: ValidacionesFEVRipsComponent. Glosas: SopFevRips / NA-RIPS.

Invariante: CUV validado **no** significa cuenta radicada (FCXC). Precondición motor: FACTE=2. Marca masiva exige FACTE=2, contabilizada, CUV vacío, no caja. Cola microservicio solo si FEVRIPS_MODO=MICROSERVICIO; TOMAR_MANUAL evita CUV duplicado. ESTADO 5 (validación) no reintenta solo — ENCOLAR tras corrección. JWT SISPRO en TRANSIENT (JWT_RIPS).
