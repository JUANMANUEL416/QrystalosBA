1. Requerimiento

Falla al validar Notas de Ajuste (NA) de respuestas a glosas: aunque las facturas tienen CUV válido ante Minsalud, la validación NA devuelve RVG018 (CUV nulo o ≠ 96 caracteres). Facturas de ejemplo: UV27556, UV27557, UV27559, UV27563, UV27584, UV28121, UV29119, UV29122. Cuatro causas reportadas: 1. numNota incorrecto (usa N_FACTURA en lugar del consecutivo de glosa). 2. No envía el CUV de la factura original al validar la NA. 3. Envía estructura de factura FV completa en lugar del JSON RIPS de NA. 4. El CUV de Minsalud no se guarda en FGLO (intervención manual en BD). Se requiere proceso automático: validar NA, persistir CUV y descargar paquete FEV-RIPS sin manual.

Criterios de aceptación

  • Emular el flujo con las facturas del listado (o equivalentes) en hotfix/UNIPSA24.
  • Confirmar con soporte/cliente si el RVG018 sí ocurre o si el proceso ya valida bien.
  • Si el error no se reproduce: no hay desarrollo; el entregable es informar que el proceso está correcto.
  • Si el error sí se reproduce: recién entonces aplicar la propuesta de la sección 4.
Regla de este REQ (y de otros iguales): no se desarrolla «por si acaso». Primero se emula el error. Solo si se confirma la falla hay cambio de código. Si no se confirma, se cierra como validación OK.
