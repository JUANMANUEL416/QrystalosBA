1. Requerimiento del cliente

En el módulo de facturación, sección autorización, incluir opción «Marcar no facturable masivamente». Se solicita que el sistema permita marcar como no cobrable toda la autorización. La versión web solo tiene la opción de hacerlo uno a uno dentro de la misma autorización.

Criterios de aceptación

1) En Administrativo → Facturación → Facturación Masiva → pestaña Autorizaciones, existe una acción visible «Marcar no cobrable (autorización completa)» sobre la fila seleccionada o en la barra del detalle expandido, que marca en un solo paso todos los ítems AUTD no facturados de esa autorización como NOCOBRABLE=1 y deja AUT.FACTURABLE=0 cuando corresponda. 2) Existe acción complementaria «Revertir no cobrable (autorización completa)» que pone NOCOBRABLE=0 en todos los ítems no facturados de la autorización y restaura AUT.FACTURABLE=1 si queda al menos un ítem cobrable. 3) Opcional acordado con negocio: botón «No cobrable masivo» en la barra superior (mismo criterio de filtros que Marcar Todo) que aplica el marcado a todas las autorizaciones visibles/no facturadas del filtro actual; reporta cuántas se procesaron y omite las ya facturadas. 4) No se permite la acción si la autorización o el ítem ya tiene factura (FACTURADA=1 o N_FACTURA); el sistema muestra mensaje claro. 5) Tras marcar, la grilla cabecera muestra Facturable desmarcado, el detalle muestra todos los toggles No Cobrar activos, el filtro «No Facturables?» incluye la autorización y no puede marcarse para facturación masiva hasta revertir. 6) Regresión: el toggle línea a línea (NOCOBRAR_AUTD) y la columna Facturable de cabecera (MARCANOCOBRABLE) siguen operando como hoy.

5. Cambios propuestos

5.0 En palabras simples (negocio)

Hoy, en Autorizaciones de facturación masiva, para dejar una autorización sin cobro hay que expandirla y cambiar el toggle «No Cobrar» en cada servicio. Se propone un botón que, en un solo paso, marque todos los servicios pendientes de esa autorización como no cobrables (y otro para revertir), con la opción de hacerlo para varias autorizaciones del filtro si el comité lo confirma.

5.1 Detalle técnico — Frontend (Qrystalos2)

  • FTRMComponent.vue — Pestaña Autorizaciones: botones «No cobrable — autorización completa» y «Revertir no cobrable» junto a acciones existentes (Marcar Todo, etc.), habilitados cuando hay fila seleccionada y AUT no facturada.
  • En detalle expandido (grilla AUTD): botones «Marcar todos no cobrables» / «Marcar todos cobrables» que llaman al mismo METODO con IDAUT de la fila expandida.
  • Diálogo $q.dialog de confirmación con conteo de ítems afectados; notificaciones OK/KO; recarga onRequestAUT y detalle AUTD.
  • Opcional (criterio 3): acción masiva por filtro — iterar o enviar IDAUTS[] con mismos filtros que MarcarAUT('1'); resumen «N autorizaciones, M ítems».
  • Regresión: toggleNoFacturarAUTD, toggleNoFacturarAUT, MarcarAUT sin cambio de contrato.
  • Permiso: reutilizar acceso a Facturación Masiva (FACT_MASIVA); permiso dedicado solo si negocio lo exige.

5.2 Detalle técnico — SQL Server

Nuevo submétodo en IXONLINE/SQL · SPQ_FTR_MASIVA_COL · NOCOBRAR_AUT_MASIVO, reutilizando reglas de NOCOBRAR_AUTD (omitir ítems facturados, USUARIOMARCA, recalcular AUT.FACTURABLE).

Opcional: en SPQ_FTR_COL · MARCANOCOBRABLE (rama AUT, NOITEM null), además del toggle AUT.FACTURABLE, ejecutar el mismo UPDATE masivo sobre AUTD pendientes para coherencia cabecera/detalle.

5.2.1 Fragmentos SQL (especificación)

Especificación para desarrollo en preversión; no ejecutar desde la oficina BA.

-- Objeto: SPQ_FTR_MASIVA_COL · METODO propuesto NOCOBRAR_AUT_MASIVO (IXONLINE/SQL)
-- Basado en lógica existente NOCOBRAR_AUTD (toggle por NO_ITEM).

-- Parámetros JSON sugeridos:
-- { "ACCION": "MARCAR" | "DESMARCAR", "IDAUT": "..." }
-- o { "ACCION": "MARCAR", "IDAUTS": ["id1","id2"] } para lote filtrado desde FE

-- AFTER (cuerpo propuesto, por cada IDAUT):
IF @ACCION = 'MARCAR'
BEGIN
  UPDATE AUTD SET NOCOBRABLE = 1, USUARIOMARCA = @USUARIO
  WHERE IDAUT = @IDAUT
    AND COALESCE(FACTURADA,0) = 0
    AND COALESCE(NOCOBRABLE,0) = 0;

  UPDATE AUT SET FACTURABLE = 0
  WHERE IDAUT = @IDAUT
    AND NOT EXISTS (
      SELECT 1 FROM AUTD d
      WHERE d.IDAUT = @IDAUT AND COALESCE(d.FACTURADA,0)=0 AND COALESCE(d.NOCOBRABLE,0)=0
    );
END
ELSE IF @ACCION = 'DESMARCAR'
BEGIN
  UPDATE AUTD SET NOCOBRABLE = 0, USUARIOMARCA = NULL
  WHERE IDAUT = @IDAUT AND COALESCE(FACTURADA,0)=0 AND COALESCE(NOCOBRABLE,0)=1;

  UPDATE AUT SET FACTURABLE = 1
  WHERE IDAUT = @IDAUT
    AND EXISTS (SELECT 1 FROM AUTD d WHERE d.IDAUT=@IDAUT AND COALESCE(d.FACTURADA,0)=0);
END
SELECT 'OK' OK, @@ROWCOUNT AS ITEMS_AFECTADOS;
