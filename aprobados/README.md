# Documentos oficiales aprobados

Dictámenes y documentos validados entre coordinador y asesor.

## Estructura

```
aprobados/
  {id-caso}/
    dictamen-final.html      # Copia del dictamen aprobado
    notas-aprobacion.md      # Observaciones del aval
    imagenes/                # Capturas del sistema (si el agente las pidió)
      pantalla-prenomina.png
```

Copie aquí el HTML del dictamen cuando ambos den el aval.
