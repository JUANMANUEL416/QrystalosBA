1. Requerimiento del cliente

Para el módulo de prestaciones sociales, al agregar un ítem de liquidación el formulario solicita conceptos cuando debe solicitar eventos, porque con base en el evento se calcula la prestación a pagar. Se pide además una validación que avise al usuario cuando no seleccione correctamente el evento. Hoy el cliente debe crear concepto y novedad con el mismo código como workaround, lo cual no es óptimo.

5. Cambios propuestos

5.0 En palabras simples (negocio)

Hoy, al agregar un ítem de liquidación en prestaciones, el sistema pide un «concepto» pero guarda en un campo que en realidad es el evento de nómina; si el usuario elige mal, falla la base de datos. Se propone que el formulario muestre y permita buscar eventos (como en novedades de prenómina) y que, si el código no es un evento válido, aparezca un aviso claro sin obligar a duplicar conceptos y novedades.

5.1 Detalle técnico — Frontend (Qrystalos2)

  • PrestacionesNominaComponent.vue: duplicar patrón de RegistNovedadesComponent.vue — diálogo SelectGenerico con tabla="NEVE", llave="IDEVENTO", columnas IDEVENTO, DESCRIPCION, CODCONCEPTO (solo lectura informativa).
  • Sustituir invocaciones dgSearchNCON en modales NVAC (insert) y NVACD por dgSearchNEVE; renombrar handler a onSelectNEVE asignando row.IDEVENTO.
  • Etiquetas y tooltips: «Código evento» / «Consultar eventos» (grilla detalle ya dice «Novedad» — mantener coherencia).
  • En onSaveNVACD / onSaveNVAC: si recordset trae OK=KO, mostrar ERROR con notify (no depender solo del diálogo genérico de SQL).
  • No modificar EventPrestacionesNomComponent.vue (PREVENT) salvo regresión visual.

-- SPQ_NOM_NVACD · METODO GUARDAR (confirmar bloque en PREVERSION)

IF NULLIF(LTRIM(RTRIM(@IDEVENTO_PAGO)), '') IS NULL
BEGIN
  SELECT 'KO' AS OK, 'Debe seleccionar el evento de nómina (NEVE) con el que se calculará la prestación.' AS ERROR;
  RETURN;
END
IF NOT EXISTS (SELECT 1 FROM dbo.NEVE WITH (NOLOCK) WHERE IDEVENTO = @IDEVENTO_PAGO)

    'El código ''' + @IDEVENTO_PAGO + ''' no es un evento válido (NEVE.IDEVENTO). Use «Consultar eventos», no conceptos de nómina (NCON).' AS ERROR;

END
